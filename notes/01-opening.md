# 第 1 节　开场 · 从 Windows 桌面到 Linux 命令行

在 Windows 的“此电脑”里，可以用鼠标查看文件夹和磁盘。在讲师的 Ubuntu Server 虚拟机里，同样是查看目录，操作变成了在提示符后输入命令。服务器上的软件安装、开发和网站部署，都会用到这种与系统交互的能力。

## 在终端查看主目录（00:45–00:48）

演示时，提示符中的 `~` 表示当前位于用户的主目录。讲师依次输入以下两条命令，每输入一条就按一次回车。

| 命令 | 画面里的结果 | 怎么理解 |
| --- | --- | --- |
| `ls` | 下一行直接出现提示符。 | 默认省略名称以点开头的条目。没有列出文件名，仍可能有隐藏文件。 |
| `ll` | 列出 `.bash_history`、`.bashrc`、`.profile` 等条目，并显示权限、所有者、大小和修改时间，随后回到提示符。 | 在讲师的环境里，`ll` 会用长格式列出隐藏条目。 |

**自己复现。** 在 Linux 终端输入 `cd ~` 回到自己的主目录，运行 `ls`，再运行 `ls -la`。这里用 `ls -la` 是因为 `ll` 常由 shell 别名提供，各环境的定义可能不同。`-a` 把以点开头的名称也列出来，`-l` 显示每个条目的详细信息。第二次输出里能找到 `.`、`..` 并看到权限列，就能确认两项参数都生效。其余文件名取决于自己的环境。[GNU Coreutils 的 ls 手册](https://www.gnu.org/software/coreutils/manual/html_node/ls-invocation.html)

切入虚拟机时，终端上方已经有 OpenSSH 软件包的安装日志和 `ifconfig` 的网卡输出。本次目录练习从下方的提示符开始，无需安装 SSH 或修改网络设置。

## 为什么要尽早练习

讲师用大数据、网络工程、前端和后端开发举例。即使用不同的编程语言，这些岗位都可能接触 Linux 服务器。写完一个网站之后，还要能在目标环境里安装软件、找到文件、部署应用。讲师建议尽早动手，靠长期使用积累经验，以能独立完成实际任务来判断自己是否入门。
